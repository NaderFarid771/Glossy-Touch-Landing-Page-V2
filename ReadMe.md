# Glossy Touch — Glassmorphism Landing Page

A responsive landing page built with pure HTML5 and CSS3, featuring a modern frosted-glass aesthetic, translucent cards, and smooth hover transitions.

## Live Demo

[View Live Preview](https://naderfarid771.github.io/Glossy-Touch-Landing-Page/)

## Key Features

- **Glassmorphism UI:** Translucent navigation header and feature cards styled using CSS `backdrop-filter` and subtle borders.
- **Semantic Structure:** Clean HTML5 structure for readability and maintainability.
- **Responsive Grid & Flexbox:** Multi-column layout that stacks smoothly on smaller screens via custom media queries.
- **Pure CSS Transitions:** Interactive hover states on buttons, links, and service cards.

## Tech Stack

- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries, Backdrop Filter)

## Project Structure

- `index.html` — Semantic HTML layout
- `style.css` — Stylesheet and responsive rules
- `README.md` — Project overview

Open `index.html` in your web browser.
